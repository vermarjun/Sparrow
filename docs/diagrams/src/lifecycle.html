Safety nets while it works

Crash

One automatic restart on the same session, then the parent gets the last screen.

Stopped without reporting

Nudged twice through the harness hook, then an "unreported" notice.

Quiet or slow

15 quiet minutes: a reminder. Over 90 minutes: the captain is told. Never killed.

Server restart

Live windows are adopted back.

Agents don't get fired for being slow. Only for being done.
