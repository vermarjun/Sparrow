  • Codex agents hired before this branch can't resume their old session from their new per-agent home; their first call restarts fresh, with context replayed.

  • Migration plan_id doesn't notice mode-only or symlink-only changes between plan and apply (§12.7).
  • Vercel source formats not supported: well-known URLs, Azure Repos, self-hosted GitLab /-/tree/, archive ZIP URLs.
