5Housekeeping: remove the junk projects

D11 created two junk projects in your DB, sparrow-skills-p2 and other: a human @captain row each, no messages, no cards. There's no CLI or API to delete a project. The script deletes only the human row, then the project if it's empty. It was tested on a sandbox DB copy.

sqlite3 ~/.sparrow/sparrow.db ".backup $HOME/.sparrow/sparrow.db.bak-$(date +%s)"
sqlite3 ~/.sparrow/sparrow.db "SELECT project_id,id,handle,kind FROM agents WHERE project_id IN ('sparrow-skills-p2','other');
  SELECT project_id,count(*) FROM messages WHERE project_id IN ('sparrow-skills-p2','other') GROUP BY 1;"
# expect only kind='human' rows and no messages; then for each project:
